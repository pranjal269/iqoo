# Deck source

`deck.html` is the source of `../deck.pdf` (9 slides, 13.333 × 7.5 in).

The deck screenshots live in `shots/`, which is **not committed** (`.gitignore`): PNGs are committed only to `prototype/person-1/screenshots-final/`. They are element captures of the real prototype, regenerated by `capture-screens.mjs`.

**Rebuild (Windows, Chrome installed):**

1. Start the prototype: `cd prototype/person-1 && npm install && npx vite --port 5179 --strictPort`.
2. Capture the screenshots, from this folder: `npm install --no-save puppeteer-core && node capture-screens.mjs`.
3. Print the PDF (the command used to produce `deck.pdf`; adjust the two paths if the repo is not at `C:\PRAMAAN`): `"C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf="C:\PRAMAAN\submission\deck.pdf" "file:///C:/PRAMAAN/submission/deck-source/deck.html"`.

Content sources are listed at the top of `deck.html`. Nothing in the deck is a measurement; every screenshot keeps its prototype stamps and sample labels.
